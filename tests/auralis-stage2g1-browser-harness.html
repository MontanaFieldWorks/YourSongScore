Auralis SonicLens: isolated browser-worker checks (Stages 2G-2–2G-6)

Nonproduction, browser-only diagnostic harness, extended from Stage 2G-1. Uses the actual analyzeEngineeringDiagnosticsInWorker and its module Worker. Synthetic modes use no songs. The separate Stage 2I-2 pilot accepts an explicitly selected local audio file. No network API calls, scoring, report changes, or production feature flag activation.

From a local YourSongScore checkout, run npm run dev and visit http://localhost:3000/tests/auralis-stage2g1-browser-harness.html. Do not serve this page from production. Progresses through 0.2, 2, 8 and 15 seconds at four sample rates for mono and stereo, stopping immediately on any failure. Each decoded PCM input is capped at 24 MiB (not a total memory limit); individual cases have a 30-second worker timeout. All memory values are optional browser-reported approximations, never process/worker peak guarantees. Wall-clock round trips are not worker CPU time. Keep this tab in the foreground during the run and avoid running multiple tests at once.

Local song pilot — READY — 0/4 completed. Select one file, then analyze it once.

Stage 2G-3 is optional and must be selected explicitly. It runs one 0.2s/48k stereo warm-up followed by three repeats each of 0.2s/48k stereo, 15s/48k stereo, and 15s/192k stereo. One case at a time, no retries, ≤24 MiB decoded PCM per case and 30s timeout per worker. Long-task/animation observers and heap snapshots are optional, not process or worker peak-memory measurements. Run in the foreground on localhost only. In-flight worker time is not worker CPU time; results can be inconclusive about a timer delay.

Stage 2G-4 must be selected explicitly. One 0.2s/48k stereo warm-up then two runs each: 15s/192k stereo, 30s/96k stereo, 60s/48k stereo. All six have 2,880,000 samples per channel, 23,040,000 PCM bytes (21.97 MiB) and 1,405 FFT frames. Strict 24 MiB per-case limit, sequential first-failure stop, no retries, 30s worker timeout, foreground-only, and optional Long Task/Long Animation Frame and memory observations. Worker wall time is not Worker CPU; memory snapshots are not process/worker peaks.

Stage 2G-5 is a separate opt-in memory-observability check: one 0.2s/48k stereo warm-up plus two runs each of 0.2s/48k stereo, 15s/48k stereo and 15s/192k stereo. Each case is capped at 24 MiB decoded PCM, 30s worker timeout, one at a time, no retries or songs. Phase snapshots of Chromium JS heap are optional, approximate and neither worker/process peaks nor proof of a leak. The main-thread copy/setup envelope and response-handler interval are not copy-only or worker CPU time. Worker FFT allocations and worker memory peaks cannot be directly measured from this test HTML; they are reported UNAVAILABLE. Evidence JSON character count is not structured-clone byte size. Keep Chrome foreground on localhost only.

Stage 2G-6 is independently opt-in via the button or ?allocation=1. It reuses Stage 2G-5's bounded warm-up and six synthetic stereo cases. Stage 2H-2A corrects its source-derived Stage 2B2 accounting: zero per-frame full-spectrum copies, with two reusable complex FFT output arrays allocated once per stereo invocation. A local runtime source-contract guard fails the run if this allocation assumption no longer matches the imported analyzer. There are still other allocations. The separate main-thread structuredClone is a proxy, not actual Worker-to-main cloning. Neither the accounting nor the clone proxy measures Worker allocations, peak RAM, CPU or a leak. Unsupported cloning is UNAVAILABLE. No DSP changes, songs or increased resource limits.

Stage 2I-1 is an explicit opt-in local-browser capacity check. It runs synthetic stereo inputs of 32, 64, 96 and 128 MiB decoded PCM at 48 kHz, once each, in order. The bridge copies each channel before transfer, so input PCM alone may occupy about twice the case size at peak, before evidence and browser overhead. Stop on first failure, no retries, 30-second timeout per Worker. This is not a general browser memory guarantee. Keep Chrome foreground and close other demanding applications first.

Stage 2I-2 is a separate local-only opt-in pilot. Select one audio file at a time (up to four files). The file stays in this browser tab: no upload, Gemini call, production scoring, or report change. Encoded files over 24 MiB are rejected before decoding; decoded PCM over 128 MiB is rejected after decoding and before Worker creation. Browser decoding itself can use more memory than these limits. The 30-second Worker timeout applies per selected file. Stop on first failure, no automatic retries. Only a small descriptive summary is shown; no raw audio or frame arrays are saved in the result. This is an engineering reality check, not a mix-quality score.

Stage 2J-1 adds seven aggregate Stage 2A frequency bands (20 Hz to 20 kHz) to the local song pilot using the existing Worker computation. A band above Nyquist is UNAVAILABLE; a band crossing Nyquist is PARTIAL. These are windowed PCM powers, not a high-frequency quality score or proof of audibility. No second main-window FFT is run.

Stage 2K requests compact Stage 1A reference meter readings inside the same Worker only for the local song pilot. LUFS, LRA, peaks and crest are descriptive; they do not identify clipping, compression, quality or audibility. The four-phase true-peak estimate is not independently certified. Existing modes and production scoring remain unchanged.

Stage 2L-1 shows the current and latest completed file above the picker; the JSON below retains the full compact history in run order. An already completed selection with the same filename, byte size and last-modified time is blocked before decoding and does not use a slot. This is session-only metadata matching, not byte-level duplicate detection: renamed copies or changed metadata may bypass it, and different files with matching metadata may be blocked. Four completed files end the session; the disabled picker then means COMPLETE, not a hang. Any failure stops the pilot with no retries. Reloading clears this page's history and duplicate guard; it does not authorize another run.
